## Suno tips

- Use **Custom Mode** to paste both the style prompt and the lyrics
- Set **title:** Zimmer frei (mich dabei)
- The `[Break]` tag signals the style change — Suno should pick up the energy shift
- If the female vocal is not dominant enough in the chorus, try adding `powerful female backing vocal, cabaret singer` to the style prompt
- Generate 2–3 versions and pick the one where the breakbeat drop lands hardest
- For the final chorus key change: Suno does not always modulate automatically — if it doesn't, note this as a manual edit in post-production
