# Project Schlager

A deliberately over-the-top German schlager project with a Tirol twist.

This repository contains the writing, structure, ideas, and development of a set of **20 German-language schlager songs**. The project leans heavily into classic alpine imagery, après-ski energy, humor, romance, and big sing-along choruses.

The goal is simple:

Create a collection of songs that feel like they belong in a **mountain hut in Tirol at midnight**, where everyone is singing along with a beer in hand.

---

# Concept

Project Schlager is intentionally exaggerated and playful.

Themes include:

- mountains  
- beer  
- romance  
- dancing on tables  
- dramatic love stories  
- après-ski chaos  
- alpine nostalgia  

Every song should be **simple, catchy and immediately singable**.

Key elements:

- strong choruses
- simple German lyrics
- emotional or humorous storytelling
- big festival / party energy

---

# Project Goals

- Write and develop **at least 20 songs**
- Maintain a consistent Tirol / alpine schlager aesthetic
- Build songs that work both for **listening and live sing-along energy**
- Keep the creative process organized using GitHub

# Songs

Each song has its own directory inside:
songs/

Example: 
songs/01-die-nacht-in-tirol

Inside every song directory:

### `lyrics.md`
Full lyrics and song structure.

### `chords.md`
Key, tempo, chord progressions and arrangement notes.

### `notes.md`
Ideas, references, production notes and development comments.

### `assets/`
Optional folder for demos, stems, snippets or artwork related to that song.

---

# Ideas

The `ideas` folder contains general inspiration and raw material.

Files may include:

- song concepts
- chorus ideas
- lyrical hooks
- theme explorations

This is where unfinished thoughts live before becoming full songs.

---

# Demos

The `demos` directory stores early musical material.

Subfolders include:

- `midi` – MIDI sketches and melodic ideas  
- `rough` – rough audio demos and work-in-progress recordings  

---

# Artwork

The `artwork` directory holds visual assets for the project.

Subfolders:

- `covers` – single or album cover art  
- `promo` – promotional graphics and visuals

# Templates

Includes:

### `song-template.md`

### `release-checklist.md`

# Writing Philosophy

Project Schlager is not meant to be subtle.

Songs should aim for:

- **big hooks**
- **simple language**
- **emotional or humorous exaggeration**
- **maximum sing-along potential**

If it feels slightly ridiculous, it is probably **exactly right**.
